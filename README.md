# 中文

## 📖 项目简介

**CNPC-EpicFight-Addon-CE-1.21.1NeoForge** 是
**CNPC-EpicFight-Addon-CE 1.20.1 Forge 社区版** 的 1.21.1 NeoForge 分支。

由于官方并没有制作 CNPC-EpicFight 附属的 1.21.1 NeoForge 版本，因此由社区继续维护并适配新版环境。

> 你官方不做有的是人做（）

本项目目标：

让 1.20.1 Forge 社区版已有的功能，逐步在 1.21.1 NeoForge 版本中继续存在。

---

## ✨ 项目目标

本分支将继续复刻并维护 1.20.1 Forge 社区版中的功能：

* CustomNPCs NPC 与 Epic Fight 联动
* NPC Epic Fight 模型支持
* Epic Fight EntityPatch 能力支持
* Epic Fight 战斗逻辑兼容
* Epic Fight 动作播放支持
* CNPC 脚本扩展支持

如果 1.20.1 Forge 社区版拥有的功能可以移植到 1.21.1 NeoForge：

那么这个版本也会继续支持。

---

## 🔗 相关版本

上一版本：

**CNPC-EpicFight-Addon-CE 1.20.1 Forge**

本项目：

**CNPC-EpicFight-Addon-CE 1.21.1 NeoForge**

两个版本目标保持一致：

为 CustomNPCs 与 Epic Fight 提供社区维护的兼容方案。

---

## 💬 关于社区版

Community Edition（社区版）并不是官方版本。

它代表：

* 社区维护
* 社区适配
* 社区扩展

由于官方没有继续提供对应版本支持，因此由玩家和开发者继续维护。

# English

## 📖 Introduction

**CNPC-EpicFight-Addon-CE-1.21.1NeoForge** is the 1.21.1 NeoForge branch of:

**CNPC-EpicFight-Addon-CE 1.20.1 Forge Community Edition**.

Since there is no official CNPC-EpicFight addon release for 1.21.1 NeoForge, this version is continued and maintained by the community.

> Things that even the official developers don't make are indeed hard to make.))

The goal of this project is simple:

Bring the features from the 1.20.1 Forge Community Edition to the 1.21.1 NeoForge version.

---

## ✨ Project Goals

This branch continues the features from the 1.20.1 Forge Community Edition:

* CustomNPCs and Epic Fight integration
* Epic Fight model support for NPCs
* Epic Fight EntityPatch support
* Epic Fight combat compatibility
* Epic Fight animation support
* CNPC script extensions

If a feature exists in the 1.20.1 Forge Community Edition and can be migrated to 1.21.1 NeoForge:

this version will continue to support it.

---

## 🔗 Related Versions

Previous version:

**CNPC-EpicFight-Addon-CE 1.20.1 Forge**

This project:

**CNPC-EpicFight-Addon-CE 1.21.1 NeoForge**

Both versions share the same goal:

Providing a community-maintained compatibility solution between CustomNPCs and Epic Fight.

---

## 💬 About Community Edition

Community Edition is not an official release.

It represents:

* Community maintenance
* Community adaptation
* Community extensions

Because official support for this version does not exist, the community continues the development.
